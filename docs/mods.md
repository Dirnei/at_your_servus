# Mods

Every mod in `mods/`, with its role in the pack. Servus is the main path; everything else fills a gap around it. Availability for Minecraft 26.1.2 / NeoForge was checked on 2026-10-19.

Side: `both` runs on client and server, `client` is left out of the server pack.

## Servus

| Metafile | Mod | Side | Role |
|---|---|---|---|
| `servus-foundation` | Servus: Foundation | both | Utility Duct, tanks, pumps, Coal Generator, tools: early logistics and early power |
| `servus-alchemy` | Servus: Alchemy | both | Resource generation and the Great Work |
| `servus-shuttles` | Servus: Shuttles | both | Warehouse, storage, autocrafting, field work, outposts; the quest backbone |
| `modonomicon` | Modonomicon | both | Paracelsus' Journal for Alchemy |

## Excluded on purpose

| Mod | Reason |
|---|---|
| Applied Energistics 2, Refined Storage | Compete with Shuttles for storage and autocrafting |
| Mystical Agriculture, Productive Bees | Compete with Alchemy as the resource mod |
| Replication | Competes with Alchemy's "make anything" endgame |
| Ender IO, Oritech | Own conduits and machine chains clash with the Utility Duct |
| Energized Power | Fallback only, if Powah turns out unusable |
| Storage Drawers, Traveler's Backpack | Duplicate Functional Storage and Sophisticated Backpacks |
| Xaero's Minimap, Xaero's World Map | FTB Chunks already has a map |
| SecurityCraft | Left out of 0.1.0 |
| Corail Tombstone | Blocks third-party downloads, so it cannot be in the server pack; GraveStone Mod instead |
| Easy Mob Farm, Tiny Mob Farm | Too easy next to built farms |
